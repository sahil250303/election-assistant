# Democracy Hub | Election Assistant

An interactive, modern web application designed to help users understand the election process, timelines, and necessary steps to vote. Built with a premium glassmorphism design.

## Features

- **Interactive Timeline**: A visual timeline showing key dates and phases in the election process (Voter Registration, Early Voting, Election Day).
- **Step-by-Step Guide**: An easy-to-follow layout explaining the voting process from registration to casting a ballot.
- **Interactive Chat Assistant**: A simulated AI-like assistant interface where users can ask common questions (or click quick-action buttons) to receive immediate answers regarding voting procedures, deadlines, and requirements.
- **Premium Aesthetics**: High-end modern web design using a curated color palette, sleek dark mode, glassmorphism effects, smooth gradients, and micro-animations.

## Technology Stack

- **HTML5**: Semantic document structure
- **CSS3**: Vanilla CSS for styling, responsive design, animations, and glassmorphism effects
- **JavaScript (Vanilla)**: DOM manipulation and simulated chat assistant logic

## Getting Started

To view and run the project locally, you don't need any special build tools since it's built with vanilla web technologies.

1. Clone the repository:
   ```bash
   git clone https://github.com/sahil250303/election-assistant.git
   ```
2. Navigate to the project directory:
   ```bash
   cd election-assistant
   ```
3. Open `index.html` directly in your web browser. 

Alternatively, you can serve the directory using a local web server (e.g., Python's `http.server` or `npx serve`):
```bash
python -m http.server 8000
# Then open http://localhost:8000 in your browser
```
